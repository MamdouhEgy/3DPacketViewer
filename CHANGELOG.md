# Changelog

## 0.2.0

Make the aligned byte-and-bit map the default. Add source-relative offset and
bit rulers, decoded field explanations, exact selection overlays, protocol
emphasis, and virtualized map picking. Keep the 3D stack as an optional
encapsulation view. Preserve the existing extractor, provenance rules and
canonical occupancy policy. Move performance counters to a tooltip.

## 0.1.0

Initial pinned-revision implementation: native modeless Wireshark UI plugin,
immutable dissection snapshots, data-source-aware bit geometry, OpenGL camera
and picking, field inspector, virtualized byte/bit display, deterministic
fixtures and automated headless and in-process GUI validation.
