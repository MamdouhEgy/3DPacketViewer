# Remaining limitations

- The native module targets the exact documented Wireshark 4.7.4 development revision. It does not load into Wireshark 4.2.2. Windows/macOS runtime, real-interface capture and field deployment are NOT TESTED.
- Protocol modules implement the documented observation/correlation profiles, not every normative state, object variation or deployment profile. MMS association negotiation, complete DNP3 application/control/authentication behavior and SCL import remain outside this release. Missing capture evidence must not be interpreted as proof of a protocol fault or attack.
- SV waveform values require the matching Wireshark decode preference/profile. No arbitrary `seqData` parser, physical scaling or engineering unit inference exists. Rate/modulus policy is currently analyzer-wide, not per stream. Sustained industrial SV throughput is NOT TESTED.
- Full-tree mode increases dissection work while the viewer is open. State stops with a partial-results diagnostic at 200,000 events, 50,000 transactions or 50,000 findings. This is not an unbounded long-running collector. CLI Wireshark frame/dissection metadata also grows with capture size.
- Native multiple selection requires the Number column and unaggregated rows; otherwise select semantic events in the plugin. Transaction navigation and filtering are supported. The plugin does not perform reverse selection of an individual native Packet Details field.
- Different-device/stream comparisons retain separate summaries. Numeric deltas between summaries are produced only for matching identities; the analyzer does not guess signal equivalence or units.
- The OpenCode catalog currently lacks API-type metadata, so adapter discovery additionally depends on the official documentation's endpoint table. Unrecognized layouts/models fail closed. Go is primarily a coding-agent service; future acceptance/availability and model retention policies may change.
- AI output is an unverified explanation/hypothesis, even after schema/evidence validation. Neither deterministic observations nor model prose establish malicious intent on their own. Session keys exist in process memory; host crash-dump and process-access controls remain the operator's responsibility.

- The host’s libproxy 0.5.4 has a reproducible 141-byte shutdown leak. The installed user bundle includes tested libproxy 0.5.12, which resolves it without suppressions. Use the bundle launcher to load this dependency. Builds using the original system dependency can still reproduce the leak; see `VALIDATION.md`.
